## 行为观察

输入与判定点见 [cases.json](../evals/cases.json)。执行者仅获 Skill 路径和任务输入，未获检查点或预期答案；仅允许读 Skill 自带资源，无联网或外部写入。

| 案例 | 检查结果与实际输出证据 |
| --- | --- |
| C-01（5项） | 分开 A 基础款与 Pro，注明 Pro 需插件；未知能力标未确认；保留单击查看、双击切换；结论引用 S1—S3 并说明未提供价格；V1 被标为未观看候选。原句：“当前材料只确认 A Pro 安装插件后支持。” |
| R-01（6项） | r1 分为兼容/外观/价格三行并摘录对应原文；明确“3 条原评论，拆为 5 行”，点赞不累加；r2 归需求；r3 不作为已证实缺陷；排除 r4、隔离 r5；六列表前有编号总结，无表后重复评价清单。 |
| D-01（6项） | 区分既定边界与候选；按用户、场景、需求、功能映射；六键旋钮未被写成要求；同任务比较桌面/手持并保留固定摆放可能；给出含任务身份、选择、定位、状态回传及断连处理的闭环；期待假设与交付顺序分别列出。 |
| W-01（4项） | 删除夸张修辞；保留单击/双击及录音后进入输入框、不自动发送；拒绝从两条偏好推断普遍付费意愿；只交付局部改写。原句：“两位评论者提到希望支持无线连接，但这还不能说明用户普遍愿意为无线多花钱。” |
